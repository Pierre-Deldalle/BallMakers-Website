# 🏀 BallMakers — Portfolio

Site web officiel de **BallMakers**, dédié à la création de contenu autour du basketball.

BallMakers propose différents services de création visuelle : photographie, vidéo et graphisme.  
Ce site permet de présenter les différentes réalisations, collaborations et services de BallMakers.

---

## 📸 Aperçu

Le portfolio regroupe plusieurs catégories de créations :

- 🎨 Visuels & affiches
- 📱 Reels & Shorts
- 🏀 Highlights joueurs
- 📷 Photos & shootings
- 🎬 Trailers
- ▶️ Vidéos YouTube

Le site est disponible en **français et en anglais** et possède une interface responsive adaptée aux ordinateurs, tablettes et smartphones.

---

## ✨ Fonctionnalités

- Portfolio de créations
- Galeries photos interactives
- Lightbox pour visualiser les créations
- Carrousels de contenus
- Intégration de vidéos YouTube
- Présentation de shootings photo et vidéo
- Formulaire de contact
- Envoi des demandes de contact via un backend
- Interface multilingue
- Design responsive

Le site a été conçu pour fonctionner sur différentes tailles d'écran :
